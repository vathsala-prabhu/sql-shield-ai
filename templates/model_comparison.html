📊 Machine Learning Model Comparison & Selection

Empirical benchmark of Random Forest versus XGBoost trained on TF-IDF character n-grams (2–5) with 20,000 maximum features.

PRODUCTION MODEL SELECTION DECISION
Selected: Random Forest Classifier
Selection Rule: Highest SQLi Recall on Validation (0.9965)

In cybersecurity firewalls, Recall is the critical performance metric. A False Negative means a live SQL injection payload successfully slips past the gateway into the application database, causing data breaches. Random Forest achieved higher validation recall (99.65% vs 99.17%) and test recall (99.12% vs 98.76%), resulting in 28% fewer false negatives than XGBoost.

🔍 Feature Engineering & Model Mechanics

Why Character N-Grams? Traditional word-level tokenizers (like space-separated bag of words) fail against SQL injection because attackers frequently omit spaces, use inline comments (/*evasion*/), or concatenate strings without whitespace ('OR'1'='1'). Character n-grams (sub-sequences of length 2 to 5 characters) capture fine-grained syntactic patterns regardless of whitespace obfuscation.

Why Random Forest over XGBoost for this dataset? While XGBoost achieved slightly fewer false positives (1 vs 3), Random Forest significantly reduced false negatives (15 vs 21). In production cybersecurity, preventing real breaches is paramount. Random Forest's ensemble of 100 decorrelated decision trees with feature sub-sampling provides exceptional resistance to overfitting on high-dimensional character n-gram matrices (20,000 features).
